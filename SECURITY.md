## Reporting a Vulnerability

We take the security of the **HV Myra Matchday Board Application** seriously. If you discover a security vulnerability or credential leak:

1. **Do NOT open a public GitHub issue**.
2. Email security vulnerability details directly to the repository maintainers.
3. Include steps to reproduce, affected endpoints, and potential impact.

Maintainers will acknowledge receipt within 48 hours and work on a fix promptly.
